# Готовность к выпуску

Пакет managed SDK `NemotronDiarizationSharp` версии `0.1.0-preview.1` опубликован. Следующее обновление планируется как `0.1.0-preview.2`; ручной workflow выпуска требует отдельного разрешения. Пакеты native runtime не опубликованы, права на их распространение не подтверждены. MIT распространяется только на оригинальные материалы проекта; для сторонних компонентов действуют собственные условия.

## Проверенная область

Проверенная среда — Windows x64 с .NET 10. Локально завершились CPU- и CUDA-сценарии записи и потоковой обработки. Это не подтверждает общую совместимость GPU и драйверов, чистую установку, Linux, несколько GPU или выполнение CUDA-ядер. SDK не содержит native DLL и требует отдельно подготовить совместимый runtime и модель. Веса модели остаются внешними; `nvcuda.dll` предоставляет установленный драйвер NVIDIA.

## Рекомендуемый путь

Начать с CPU: сохранённые DLL совпадают с записями официального архива NeMo-Speech.cpp v0.2.0, а Microsoft CRT/OpenMP остаётся внешней предпосылкой. Это подтверждает идентичность байтов, но не происхождение сборки и не право распространения. До выпуска нужны достоверные сведения о конфигурации сборки и полном составе зависимостей, применимых лицензиях и уведомлениях (особенно KenLM/LGPL и Darts), а также право на распространение и минимальная версия Microsoft runtime. Если эти сведения недоступны, заменить бинарные файлы воспроизводимой сборкой из закреплённых исходников с проверенными зависимостями.

Для CUDA отдельно подтвердить происхождение и состав сборки, уведомления, условия NVIDIA CUDA для повторно используемого NuGet-пакета, а также право распространять включённые VC145 CRT и VC143 OpenMP DLL. CUDA/cuBLAS перечислены в условиях NVIDIA как потенциально распространяемые компоненты только при выполнении условий включения в приложение; это не является разрешением для данного пакета. Некоторые сторонние компоненты имеют MIT/Apache уведомления, но их применимость к DLL пока полностью не подтверждена. Веса модели не включать и не считать разрешёнными к распространению.

Технические проверки упаковки и установки не заменяют оценку прав. Публикация runtime-пакетов не разрешена.
