# Готовность к выпуску

Исходный код управляемого SDK лицензирован по MIT. NuGet-пакеты не опубликованы; проверка прав на распространение native runtime не завершена. MIT распространяется только на оригинальный код проекта. Для каждого стороннего компонента действуют собственные лицензии, уведомления и условия распространения.

## Подтверждённая область

Проверенная среда — Windows x64 с .NET 10. В локальных проверках завершились CPU- и CUDA-сценарии записи и потоковой обработки. Эти результаты не подтверждают общую совместимость с GPU и драйверами, установку на чистой машине, поддержку Linux, работу с несколькими GPU или атрибуцию исполнения CUDA на уровне ядер. Эти возможности остаются непроверенными.

Управляемый SDK не содержит native DLL и требует отдельно предоставить совместимый runtime и модель. CPU- и CUDA-пакеты runtime предназначены для Windows x64. Targets сборки копируют native-файлы, не фильтруя неподдерживаемые платформы потребителя. Веса модели остаются внешними. `nvcuda.dll` поставляется установленным драйвером NVIDIA и не входит в пакет.

## Статус пакетов

| Пакет | Содержимое | Статус |
|---|---|---|
| `NemotronDiarizationSharp` | Управляемый SDK `net10.0`, README, сведения о распространении и лицензия MIT. Без native-файлов. | MIT распространяется на оригинальный код SDK, принадлежащий проекту. Managed-пакет SDK не опубликован. |
| `NemotronDiarizationSharp.Runtime.Cpu` | Пять engine DLL для Windows x64 и применимые уведомления. | Не опубликован; проверка происхождения бинарных файлов, состава зависимостей, уведомлений и условий распространения не завершена. Нужен внешний Microsoft Visual C++ x64 runtime, включая OpenMP. |
| `NemotronDiarizationSharp.Runtime.Cuda` | Тринадцать engine, CUDA/cuBLAS и Microsoft runtime DLL для Windows x64 с применимыми уведомлениями. | Не опубликован; проверка состава бинарных файлов и условий распространения NVIDIA и Microsoft не завершена. |
| `NemotronDiarizationSharp.AllRuntimes` | Пакет только с зависимостями SDK и обоих native runtime-пакетов. | Не опубликован; необходимо соблюсти условия распространения CPU- и CUDA-пакетов. |

Успешная сборка пакета или восстановление зависимостей потребителя не являются юридическим разрешением. Targets runtime-пакетов копируют DLL, но не копируют лицензионные материалы в выходные каталоги приложения. Любое отдельно разрешённое распространение runtime должно включать применимые уведомления и соблюдать исходные условия. Сторонние компоненты и native-бинарные файлы не переходят под MIT-лицензию SDK.
