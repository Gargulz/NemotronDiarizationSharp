# Готовность к выпуску

Кандидат пакета managed SDK — `NemotronDiarizationSharp` версии `0.1.0-preview.1`. Это пакет только с managed SDK; перед отдельной разрешённой публикацией его нужно собрать и проверить локально. В рамках этой подготовки пакет не публиковался. Проверка прав на распространение native runtime не завершена. MIT распространяется только на оригинальные материалы проекта; для каждого стороннего компонента действуют собственные лицензии, уведомления и условия распространения.

## Подтверждённая область

Проверенная среда — Windows x64 с .NET 10. В локальных проверках завершились CPU- и CUDA-сценарии записи и потоковой обработки. Эти результаты не подтверждают общую совместимость с GPU и драйверами, установку на чистой машине, поддержку Linux, работу с несколькими GPU или атрибуцию исполнения CUDA на уровне ядер. Эти возможности остаются непроверенными.

Управляемый SDK не содержит native DLL и требует отдельно предоставить совместимый runtime и модель. CPU- и CUDA-пакеты runtime предназначены для Windows x64. Targets сборки копируют native-файлы, не фильтруя неподдерживаемые платформы потребителя. Веса модели остаются внешними. `nvcuda.dll` поставляется установленным драйвером NVIDIA и не входит в пакет.

## Статус пакетов

| Пакет | Содержимое | Статус |
|---|---|---|
| `NemotronDiarizationSharp` | Managed SDK `net10.0`, README, сведения о распространении и лицензия MIT. Без native-файлов и модели. | Локальный prerelease-кандидат `0.1.0-preview.1`; эта задача не разрешает публикацию. |
| `NemotronDiarizationSharp.Runtime.Cpu` | Локальный проект для пяти engine DLL Windows x64 и применимых уведомлений. | Не входит в managed prerelease и недоступен в NuGet. Проверка происхождения бинарных файлов, зависимостей, уведомлений и условий распространения не завершена. Нужен внешний Microsoft Visual C++ x64 runtime, включая OpenMP. |
| `NemotronDiarizationSharp.Runtime.Cuda` | Локальный проект для тринадцати engine, CUDA/cuBLAS и Microsoft runtime DLL Windows x64 с применимыми уведомлениями. | Не входит в managed prerelease и недоступен в NuGet. Проверка состава бинарных файлов и условий распространения NVIDIA и Microsoft не завершена. |
| `NemotronDiarizationSharp.AllRuntimes` | Локальный dependency-only проект для SDK и идентификаторов обоих native runtime-пакетов. | Не входит в managed prerelease и недоступен в NuGet. Требуется соблюсти условия распространения CPU- и CUDA-пакетов. |

Метаданные managed-пакета указывают публичный GitHub-репозиторий. Связанный `.snupkg` содержит portable debug symbols с Source Link. `.nupkg` не зависит от локальных CPU, CUDA или AllRuntimes проектов. Наличие проектов пакетов в репозитории не означает, что их можно подключить как опубликованные зависимости.

Успешная сборка пакета или восстановление зависимостей потребителя не являются юридическим разрешением. Targets локальных runtime-проектов копируют DLL, но не копируют лицензионные материалы в выходные каталоги приложения. Любое отдельно разрешённое распространение runtime должно включать применимые уведомления и соблюдать исходные условия. Сторонние компоненты и native-бинарные файлы не переходят под MIT-лицензию SDK.

## Перед первой публикацией preview

1. Проверить и принять точный локально проверенный commit и release notes.
2. Убедиться, что `.nupkg` называется `NemotronDiarizationSharp.0.1.0-preview.1.nupkg`, содержит только managed SDK и предусмотренные файлы документации/лицензии, а версия, лицензия, репозиторий и Source Link указаны правильно.
3. После отдельного разрешения HUMAN опубликовать только managed-пакет. Не публиковать CPU, CUDA или AllRuntimes до завершения проверок происхождения и прав на распространение.
4. Проверить восстановление опубликованного пакета в чистом проекте .NET 10 и обновить сведения о доступности с фактической публичной ссылкой.
